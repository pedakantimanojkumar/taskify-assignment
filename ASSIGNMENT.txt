Q2. Automated Form Filling
--------------------------

To fill multiple forms automatically within 5 minutes, I would use Python with Selenium.

Why Selenium:
- I know Python well
- Selenium can control the browser and fill forms automatically
- It waits for pages to load before filling next fields

Basic steps:
1. Open browser using Selenium WebDriver
2. Go to signup/login page
3. Find form fields by ID or name
4. Fill in the data using send_keys()
5. Click submit button
6. Wait for next page and repeat

I wrote a working script that fills our webapp form automatically. It adds multiple users without manual input.

The script handles:
- Waiting for elements to load
- Filling text inputs
- Clicking buttons
- Moving through multi-step forms

GitHub: https://github.com/pedakantimanojkumar/form-automation
